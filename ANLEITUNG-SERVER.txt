================================================================================
WICHTIG – IHR SCREENSHOT ZEIGT DAS FALSCHE / UNVOLLSTÄNDIGE PROJEKT
================================================================================

Im Fenster steht:
  „Arbeitsplan - Windows Server Start“

Unser aktuelles Skript zeigt IMMER:
  „SCHICHTWERK - 00-START“
  oder „Schichtwerk - Windows Server Start“

Wenn „Arbeitsplan…“ erscheint, wird eine andere/alte BAT ausgeführt
oder der Ordner C:\Arbeitsplan enthält nicht den Schichtwerk-Code.


Was im Explorer in C:\Arbeitsplan sichtbar war
----------------------------------------------
Nur u.a.:
  node_modules
  public
  sources
  starten-server-fenster-offen.bat
  installieren.bat

Das reicht NICHT. Es fehlen typischerweise:
  package.json
  src
  prisma
  scripts
  00-START.bat


Bitte so neu aufsetzen (genau so)
---------------------------------
1) Alten Ordner C:\Arbeitsplan umbenennen, z.B. in C:\Arbeitsplan-ALT
   (nicht löschen, falls Sie Dateien behalten wollen)

2) Diesen ZIP herunterladen:
   https://github.com/xXLaser/Schichtplaner/archive/refs/heads/cursor/schichtplaner-tool-94b2.zip

3) ZIP entpacken. Es entsteht z.B. ein Ordner:
   Schichtplaner-cursor-schichtplaner-tool-94b2

4) Den INHALT dieses Ordners nach C:\Schichtwerk kopieren
   (oder den Ordner selbst nach C:\Schichtwerk umbenennen/verschieben)

5) Im Explorer C:\Schichtwerk öffnen. Sie MÜSSEN sehen:
   - 00-START.bat
   - package.json
   - src          (nicht „sources“)
   - prisma
   - scripts
   - public
   - starten-server.bat
   - PRUEFEN.bat

6) Doppelklick auf:
   C:\Schichtwerk\00-START.bat

7) Im schwarzen Fenster muss ganz oben stehen:
   SCHICHTWERK - 00-START

8) Warten (erster Build kann 2–5 Minuten dauern). Danach testen:
   http://localhost:3000/api/health


Falls wieder „Arbeitsplan…“ erscheint
-------------------------------------
Dann wurde erneut die alte BAT aus C:\Arbeitsplan gestartet.
Bitte wirklich C:\Schichtwerk\00-START.bat verwenden.
